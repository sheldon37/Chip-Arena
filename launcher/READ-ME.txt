CHIP ARENA - WINDOWS x64 PORTABLE SERVER

1. Right-click the ZIP and choose Extract All. Open the extracted folder.
2. Double-click Start-Chip-Arena.bat. The game opens in your browser.
3. Keep the server window open. Close it or press Ctrl+C to stop.

Node is included. You do NOT need npm, a terminal command, an installer,
administrator access, or a ChatGPT account. Windows 10/11 x64 is required.
The .bat launches the included official node.exe and the bundled game server.
This prototype bundle is not code-signed. Do not run it from inside the ZIP.

PLAY WITH A FRIEND
Same network: share the LAN link printed by the launcher. If Windows asks,
allow the server on your private network. Both players use that link, then
Create Room / Join Room or the in-game invite link.

Different networks: double-click Start-Online.bat instead. Its first run
downloads the official Cloudflare connector and verifies its checksum.
It prints and opens a temporary HTTPS game link. Share that link, create a
room, then use the room code/invite. No accounts or router configuration.
Anyone with the link can access this temporary prototype server. It closes
when you stop the launcher. This free testing tunnel has no uptime guarantee.
Do not run both launchers at once. Internet access is needed for online mode.

The usual published Chip Arena website has separate rooms. To use YOUR laptop
server, both players must use the link from this launcher. Existing website
rooms are not automatically redirected to your laptop.

CONTROLS
WASD move | Mouse aim | Left click attack | Right click timed block
Space jump | Shift dash | R reload | E specialization secondary
V first/third person | Tab player/chip board | M mute | Escape menu

TROUBLESHOOTING
Port in use: close your previous launcher. Changing launcher/start.mjs is
not necessary; advanced users can set PORT before launching (default 8788).
An online tunnel may fail on restricted networks. Local/LAN play still works.
Keep the whole extracted folder together. No installation or persistent
background service is created. Match state ends when the server stops.

Included runtime: Node.js 24.21.0, official Windows x64 release.
Runtime license: runtime/NODE-LICENSE.txt
Editable game source and technical notes: chip-arena-source.zip
