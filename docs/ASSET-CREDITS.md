# Arena expansion assets

The user supplied the Moonlit Wilderness image reference and the file named
`Tekken_5_OST_-_Moonlite_Wilderness_-_(mp3.pm).mp3` for this game update.
`public/music/moonlit-wilderness.mp3` is a full-length transcode of that supplied
recording (approximately 226 seconds). It is not an original composition by this
project. The source filename identifies it as Tekken 5's Moonlite Wilderness.

The nine other added tracks are original procedural compositions generated by
`scripts/generate-map-music.mjs`. The original ten tracks remain generated by
`scripts/generate-music.mjs`. Map geometry/scenery is authored in code; the image
reference is not embedded as a game texture.
