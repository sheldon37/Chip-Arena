CHIP ARENA - WINDOWS DESKTOP EDITION

SETUP
1. Extract the entire ZIP (do not run from inside the ZIP).
2. Open Chip-Arena-Desktop and double-click Chip Arena.exe.
3. Keep all the included files together. No Node install or .bat is needed.
Windows 10/11 x64. The game application is not signed with a publisher certificate.

PLAY
Chip Arena.exe opens directly to the game main menu. No server starts yet.
Play vs Bots: choose an arena, 1-7 bots, and their difficulty; runs locally.
Create Room: starts the authoritative server automatically. Online room is
on by default and creates a public connection for friends. Turn it off for LAN.
Choose a map and 0-7 bots (eight pilots total). In the lobby, the host can
change arena, bot count and difficulty. Changes reset human Ready states.
Bots are ready automatically. Wait for your group, then everyone presses Ready.
Join Room: enter the host's CA-XXXX-XXXX code or complete room invite link.
Website-hosted eight-character room codes also work. Joining starts no server.

SHARING
In an online room, use Copy Code after the online join code appears. Friends
enter it in Join Room on the updated app or Chip Arena website. Code lookup
finds the host's public link; gameplay connects to the authoritative server.
The host uses a fast local connection even while public DNS warms up.
If code lookup is unavailable, use Copy Invite Link. For LAN-only rooms,
share the local-network invite link with friends on the same Wi-Fi/network.
Each newly created room has a new code. Keep the host open. Leaving your room
or closing the app stops your hosted server and disconnects its players.
Game > Connection tools shows server logs and local/public health checks.
Press Alt to show the app menu; F11 toggles fullscreen.

ARENAS & MUSIC
Eleven arenas: Shatter Foundry, Moonlit Wilderness, Neon District,
Freight Terminal, Skyline Exchange, Reactor Nine, Dusk Outpost,
Fallen Citadel, Frostline Depot, Canal Night Market and Obsidian Forge.
Moonlit Wilderness has a flat dandelion field, moon and castle backdrop, with
your full supplied Tekken 5 Moonlite Wilderness song. Other new arenas have
nine original map tracks; Foundry shuffles the original ten tracks.
Use Settings > Soundtrack volume to adjust music separately from effects.

EIGHT-PLAYER RULES
Free-for-all. One life each round; the last living player wins that round.
Two round wins earn a set; five sets win the match. Players who lost the set
draft one Chip each, in sequence. The host can instead let everyone draft.
All current lobby players must be ready; wait for your full group before readying.
Tab shows every player's build. Leaving during a match forfeits after 12 seconds;
one player leaving does not end a match that still has multiple connected players.
Join-in-progress is disabled. Departed seats can be replaced in the lobby.

PERFORMANCE
The desktop build bundles Electron/Chromium and the existing WebGL game. It is
not a port to a different engine and does not guarantee higher FPS by itself.
Auto graphics caps physical render pixels and lowers resolution after sustained
low frame rate. Performance mode disables shadows and lowers render resolution.
Impact sparks are batched into one draw call. The game keeps armor and projectile
glows. Settings has Auto / High / Performance; try Performance if frames stutter.
Network delay and FPS drops are different problems: a tunnel may still add latency.

UPDATES
Use Update Game on the main menu or in Settings. It checks for game-content
updates, asks before closing a hosted room, and keeps the saved account login.
Startup and practice work from the installed copy without an update request.
This 0.3.6 startup change requires the desktop patch or full ZIP once, because
the in-game updater does not replace the desktop shell or its runtimes.
Updates are stored in resources/game; extract to a writable Games folder.
The Node runtime and public connector are included. No separate download or
server .bat is needed. Account customization syncs when connected to the service.

SOURCE & VALIDATION

HISTORICAL NOTES (0.3.1-0.3.5; current instructions are above)

CONNECTION RETRY UPDATE (0.3.1)
New tunnel addresses are checked before opening. Temporary DNS or gateway errors
retry automatically for up to two minutes. A failed connection keeps your hosted
server running. Use Retry connection for the same address; use Stop server only
when you want to end hosting. This does not change Windows DNS settings.

LOCAL HOST CONNECTION UPDATE (0.3.2)
Host online uses the same Node server as the .bat launcher. Your game connects
straight to http://127.0.0.1:<port>, so public DNS failure cannot block your local
connection. Friends use the public URL. Copy Invite Link includes the public
URL and room code even when the host is connected locally.
The launcher has Server log & connection checks: see the process ID, local address,
Cloudflare output, and separate local/public health results. Press Alt, then Game >
Launcher to return there without closing your game. A registered tunnel does not
prove your friend's DNS/network can reach its URL. Check connections reports the
result from your PC; friends can still have a different DNS result.

COMBAT NETWORKING UPDATE
The server negotiates fast WebSocket compression and bounds pending snapshots,
reducing upload traffic and preventing slow clients from queuing obsolete states.
Ping uses a monotonic local clock. Lobby / Esc > Connection report shows the actual
endpoint, FPS, ping, server simulation cost, event-loop delay, queue sizes and
compression status. Copy reports from both players while lag is happening.
This game update installs through the existing updater when the host restarts.
No new .bat or desktop runtime is required. Network route and PC performance can
still cause latency; this update does not guarantee a particular Internet ping.

SELECTIONS AND EASY JOIN UPDATE (0.3.3)
