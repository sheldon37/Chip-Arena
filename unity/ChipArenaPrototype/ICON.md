# Voxel CA launcher icon

`Assets/ChipArena/Branding/CAVoxelIcon.png` is the transparent, 1254 × 1254 master icon. It was generated for this project with the built-in image-generation tool on 2026-10-06. The original generated pixels and alpha channel are preserved.

`PrototypeBuild.Prepare` loads this texture and fills Unity's default and standalone application icon slots at the sizes reported by the Editor. Opening the test arena or running the Windows build applies it. The build checks that Unity retained the assignments before proceeding. Windows embedding and small-size appearance still need a real player build and Windows review.

Unity embeds the icon in the game EXE; a Windows shortcut pointing to that EXE uses its embedded icon. The PNG is not a replacement for the game executable.

## Generation prompt

Use case: logo-brand. Asset type: Windows game executable and desktop launcher icon for Chip Arena. Create one polished, stylized voxel monogram with exactly the uppercase letters "CA", C on the left and A on the right, instantly readable at small icon size. Bold chunky letters assembled from a small number of clean cubic voxel blocks, shallow three-dimensional extrusion, slightly elevated near-frontal view. Strong silhouette, crisp stepped pixel geometry, simple attractive game-like material and lighting, minimal fine detail. Center the complete monogram in a square image with a modest safe margin, filling most of the canvas. Transparent background, no ground plane or cast shadow beyond the mark. No other text, no extra symbols, no surrounding scene, no watermark. This is the final icon asset, not an icon shown on a desktop or in a mockup.
