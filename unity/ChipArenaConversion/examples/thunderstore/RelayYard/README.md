# Relay Yard

A two-sided arena for eight pilots with solid mesh cover. Select **Relay Yard** in room options and **Relay Saber** in the Melee loadout. The saber uses sword combat timing and a custom attack pose. Its Coil Edge chip adds 10% damage and is eligible only for Relay-family weapons.

Requires a Chip Arena build with the native community content loader. Extract this package into its own folder under **Mods/Community**, or install into a supported manager profile. Restart the game after changing packages. Everyone in a player-hosted room needs matching content.
